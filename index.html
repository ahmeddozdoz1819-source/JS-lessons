Array Iteration

Iterate arrays using forEach, map, filter, reduce, find.

// reduce - accumulate to single value
const sum = nums.reduce((acc, n) => acc + n, 0);

Promises

▼

Understand Promises - objects representing eventual completion of async operations.

Example 
// Create a Promise
const myPromise = new Promise((resolve, reject) => {
    let success = true;
    if (success) {
        resolve("Operation succeeded!");
    } else {
        reject("Operation failed!");

});

    .catch(error => console.log(error));

Optional Chaining & Nullish

▼

Safely access nested properties with optional chaining and nullish coalescing.

Example 
const user = {
    name: "John",
    address: {
        city: "NYC"
    }
};

// Optional chaining (?.)
console.log(user?.name);        // John
console.log(user?.address?.city); // NYC
console.log(user?.phone);        // undefined

// Nullish coalescing (??)
const value = null ?? "default";
console.log(value);  // "default"

const num = 0 ?? 100;
console.log(num);    // 0 (not falsy, but nullish)
